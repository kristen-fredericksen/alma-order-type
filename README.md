# Alma Order Type Decision Tree

A decision tree that helps CUNY library staff choose the correct Alma purchase order line (POL) order type. Answer a few questions about what you're ordering, and the tool recommends the right order type with an explanation.

**Live:** [ols.cuny.edu/alma/order-type.html](https://ols.cuny.edu/alma/order-type.html)

## What it does

- Walks through 2-4 questions based on what you're ordering (physical items, electronic titles, packages, access fees, APCs, or non-library resources)
- Recommends one of CUNY's standard Alma order types with an explanation of what to expect
- Lists order types that exist in Alma but are not recommended at CUNY, with their recommended alternatives

## How it works

A single self-contained HTML file with vanilla JavaScript — no build step, no dependencies. The decision tree data and all styles are inline. The page can also be embedded as an Alma widget (it automatically hides the header and footer when loaded inside an iframe).
